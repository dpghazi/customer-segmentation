# Customer Segmentation with Unsupervised Machine Learning

## Project Description
In this project, I work with consumer finance data from the [US Federal Reserve](https://www.federalreserve.gov/econres/scfindex.htm). I build unsupervised machine learning models to segment households that fear they will be unable to get credit.

### Overview
* Compare characteristics across subgroups using side-by-side bar charts
* Build k-means clustering models
* Conduct feature selections for clustering based on variance
* Reduce high-dimensional data using principal component analysis (PCA)

### Tools & Libraries 
* Python (Pandas, Matplotlib, Seaborn, Scikit-learn, SciPy)
